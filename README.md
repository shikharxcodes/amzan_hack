# 🚀 Alexa+ Study Planner

An AI-powered study coach built for the Amazon Hackathon. It helps students track tasks, manage exams, and plan study schedules using custom Model Context Protocol (MCP) tools and AI integration.

---
made by  shikar_coder and team member including 2
## 📌 Features

- **Task Management**: Add study tasks with priorities and automated due-date resolution (today, tomorrow, YYYY-MM-DD).
- **Alexa+ Integration**: Chat interface designed to respond like Alexa+ to manage study routines.
- **Smart Priority System**: Automatically ranks tasks by urgency (High, Medium, Low).
- **Persistent Storage**: Saves task and exam data locally.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Node.js, Express.js
- **Protocols & Tools**: `@modelcontextprotocol/sdk` (MCP Server & Client), Zod validation
- **Environment Management**: `dotenv`
